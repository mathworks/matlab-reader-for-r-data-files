# Reporting Security Vulnerabilities

If you believe you have discovered a security vulnerability, please report it
to [product-security@mathworks.com](mailto:product-security@mathworks.com). Please see the
[MathWorks Vulnerability Disclosure Policy for Security Researchers](https://www.mathworks.com/company/aboutus/policies_statements/vulnerability-disclosure-policy.html)
for additional information.

The runtime reader does not execute R&reg; code. It parses bytes and converts
supported data objects only.
